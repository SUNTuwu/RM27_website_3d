## 3. 引导页：从“品牌宣言”改成“进入体验”

### 3.1 打字文案

位置：`src/components/intro-screen.tsx`，常量 `LINES`，当前 18–29 行。

当前问题：

- `We're ENTERPRIZE Team.` 不符合自然英文表达。
- 第二句和下方中文段落重复“星舰 / 前人未至”的意象，却没有告诉新用户自己接下来会做什么。
- 首屏信息应完成三个心理任务：确认“这是谁”、建立“这群人做什么”的想象、给出“下一步是什么”。当前前两项重复，第三项突然由大红按钮承担，所以“启航”显得突兀。

固定替换为：

```ts
const LINES: Segment[][] = [
  [
    { text: "We are " },
    { text: "ENTERPRIZE", emphasis: true },
    { text: "." },
  ],
  [{ text: "We build the machines that carry us beyond the known." }],
];
```

### 3.2 中文承接段

位置：同文件，`motion.p`，当前 354–362 行。

固定替换为：

> 队名取自《星际迷航》的星舰 Enterprise。我们不只仰望远方，而是亲手造出抵达那里的机器。在这里，你会和队友一起设计、制造、调试真正的机器人，把图纸上的方案送上赛场。

理由：

- 删除“全国最大的大学生机器人赛场”这一未经当前文档核验的最高级表述。
- 从“驾驶战舰”的旁观想象转到“设计、制造、调试”的可参与行为，降低零基础访客的距离感。
- 末句自然把注意力交给下一步的 3D 赛场，而不是再次复述队名由来。

### 3.3 CTA 文案、间距和视觉重量

位置：同文件，CTA 容器与按钮，当前 364–407 行。

固定文案：

```text
ENTER THE ARENA
BEGIN EXPLORE SEQUENCE
```

固定布局改法：

| 当前值 | 改为 | 原因 |
| --- | --- | --- |
| 容器 `className="relative mt-12"` | `className="relative mt-16 md:mt-20"` | 移动端至少 64px、桌面至少 80px 的视觉停顿，让说明文字先被读完 |
| 动画初始 `scale: 0.7` | 只保留 `opacity: 0, y: 18` | 大按钮从 70% 弹出会强化“突然闯入”的感受 |
| `px-10 py-5 md:px-24 md:py-7` | `px-8 py-4 md:px-12 md:py-5` | 从海报级主视觉缩回明确的命令控件 |
| `Rocket` 图标 | `ArrowRight` 图标 | 用户需要理解“进入下一步”，不需要再猜“火箭 / 启航”隐喻 |
| 中文主字 `text-3xl ... md:text-5xl` | 英文主字 `text-xl font-bold md:text-2xl` | 英文较长，字号过大会破坏按钮稳定尺寸 |
| 强红光 `0 12px 44px rgba(...,.42)` | 最大模糊 24px、透明度不高于 .24 | 保留品牌红，不让按钮成为引导页最刺眼的发光体 |

交互状态必须补齐：

- 点云未准备好：按钮显示 `PREPARING ARENA…`，禁用点击，但页面仍允许用户读完文案。
- 点云已准备好：显示 `ENTER THE ARENA`。
- 键盘焦点：必须有清晰描边，不能只依赖 hover 缩放。
- `prefers-reduced-motion`：不做位移弹入，直接淡入。

### 3.4 穿越效果去眩光

位置：同文件，当前 412–445 行。

按图层处理：

1. 保留 412 行 `{phase !== "typing" && <WarpCanvas />}`。这是用户要求保留的穿越星线。
2. 删除 414–429 行中心径向白/青 `mixBlendMode: "screen"` 图层。
3. 删除 431–445 行 `bg-white` 全屏白闪图层。
4. `onLaunch` 触发点继续由现有 `LAUNCH_AT` 管理；不要因为删掉白闪而把回调提前到按钮点击瞬间。
5. 不修改 `src/config.js` 171–176 行的 `VISUAL_CONFIG.bloom`。它只控制 Three.js 场景后处理。

删除白闪后，为防止切换变成硬切，应让引导层自身在最后 350–500ms 从 `opacity: 1` 平滑降到 0；底下点云必须已经提交至少一帧。

## 4. EXPLORE：让用户知道“这里是什么、可以做什么”

### 4.1 左上角主标题：从品牌重复改为叙事入口

承载位置：

- 结构：`index.html` 27–31 行，稳定锚点 `.masthead`、`.masthead__eyebrow`、`.masthead__title`。
- 视觉：`src/styles.css` 268–310 行的 `.masthead__*`，以及 1347 行之后的移动端规则。
- 进入时机：`src/main.js` 的 `setState(next)`（当前约 860 行）在状态切换为 `explore` 时触发；若采用纯 CSS 分行揭示，不需要在这里逐字修改 DOM。

原方案 `WHERE STEEL MEETS WILL / OUR BATTLEGROUND` 仍然只给出气氛，没有说清 ENTERPRIZE 在这里做什么。EXPLORE 左上角应传递三层信息：用户进入我们的赛场、我们把想法造为真实机器、这些机器最终走向对抗。

#### 最终选定方案 A：想象 → 制造 → 上场

```text
WELCOME TO OUR BATTLEGROUND

WE IMAGINE.
WE BUILD.
WE BATTLE.

在这里，我们把想象做成机甲，让热爱驶向赛场。
```

方案 A 已由需求方确认，是唯一实施与验收稿。三句英文足够短，适合大字号逐行打出；中文不是英文直译，而是把团队做什么说具体。相比“我们创造奇迹”，它能被后续机器人、赛场和赛事内容直接证明，不会像空泛口号。

决策记录：此前讨论的 B（想象具象化）、C（工程链路）和 D（团队协作）均不实施，不得从中抽取句子与方案 A 混用。

不建议使用 `WE CREATE MIRACLES`、`MAKE THE IMPOSSIBLE POSSIBLE` 或“我们创造奇迹”：这类表达无法提供新信息，也会把真实的工程积累写成泛化的热血口号。英文使用 `BATTLEGROUND` 而非 `BATTLEFIELD`，前者更接近竞赛与较量，避免过强的真实战争语义。

最终实施结构固定为：

```html
<span class="masthead__eyebrow">WELCOME TO OUR BATTLEGROUND</span>
<h1 class="masthead__title" aria-label="We imagine. We build. We battle.">
  <span class="masthead__line">WE IMAGINE.</span>
  <span class="masthead__line">WE BUILD.</span>
  <span class="masthead__line">WE BATTLE.</span>
</h1>
<p class="masthead__lead">在这里，我们把想象做成机甲，让热爱驶向赛场。</p>
```

打字表现不要用 `setTimeout` 每个字符重排 DOM。完整文字一开始就进入布局，每行用 `clip-path` 或遮罩配合 `steps()` 依次揭示；这样文字占位稳定，也不会和引导页打字、点云初始化争抢主线程。实施约束：

1. eyebrow 先出现，三行标题依次揭示，总时长控制在 1.8–2.4 秒，中文说明最后淡入。
2. 只在首次进入 `EXPLORE` 时播放；切换模型不重播，进入 `SCAN` 后不重播。
3. `.masthead__title` 预先保留三行高度，揭示过程不得推动其他 HUD 位移。
4. `prefers-reduced-motion: reduce` 下直接显示完整文案，不使用逐字效果。
5. 桌面端标题区最大宽度建议 560px；移动端允许按英文行边界换行，不得使用 `white-space: nowrap`，也不得覆盖右上角状态芯片。

### 4.2 模型面板文案：从资产说明改为兵种特色

位置：`src/main.js` 的 `exploreModels`，当前 126–161 行；`index.html` 62–77 行。

固定替换如下。描述只回答“它有什么独特能力、这种能力让人联想到什么”，不再向普通用户解释 glTF、表面采样或点云生成过程：

| key | 当前名称 | 新名称 | 新说明 |
| --- | --- | --- | --- |
| `arena` | `RMUC ARENA` | `RMUC ARENA` | 这里不是背景，而是所有战术发生的坐标。功能区、增益点与掩体，让每一次移动都成为决策。 |
| `robot` | `ROBOT_1` | `ROBOT PROTOTYPE` | 从轮廓到整机，这是想象第一次获得重量与力量的地方；每一代原型，都让下一次上场更近一步。 |
| `dart` | `DART` | `DART SYSTEM` | 制导飞镖如航天器修正航迹，以高速机动逼近目标，在唯一的窗口里一击定局。 |
| `infantry` | `INFANTRY` | `INFANTRY` | 串联腿赋予步兵高机动性与地形跨越能力；它在障碍之间连续奔行，如同穿梭于星辰。 |
| `engineer` | `ENGINEER` | `ENGINEER` | 独特的月球车设计为复杂地形而生；像探索车驶过陌生月面，它把工程作业能力送达赛场的每个角落。 |

同时修改：

- `index.html` 63 行 `.explore-panel__sub`：`ENTERPRIZE / ROBOMASTER` 改为 `EXPLORE THE ARENA // MEET THE MACHINES`。不要使用 `SELECT A POINT-CLOUD ARCHIVE`，它仍然是产品内部分类语言，不是用户动机。
- 所有中文描述使用全角中文标点，不再写 `点云, 源自...`，也不出现 `glTF`、`表面采样`、`高精度模型` 等制作说明。
- `ROBOT PROTOTYPE` 是在无法从当前 `robot_1` 资产名确认具体兵种时的安全名称。若资产负责人能确认真实车型，再统一改为正式兵种名；不可同时保留两个都叫“步兵”的条目。
- `DART SYSTEM`、`INFANTRY`、`ENGINEER` 保留正式兵种识别，太空意象只进入说明，不把正式兵种名改成虚构型号。

### 4.3 滚动和操作提示

位置：

- `src/config.js` 64–85 行，`VISUAL_CONFIG.explore.scrollCue.text`。
- `src/ui/hud.js` 14–40 行，`STATE_META`。

固定修改：

```js
text: "SCROLL TO INITIATE SCAN"
```

EXPLORE HUD：

```text
CLICK 点按波纹 · DRAG 环绕观察 · SCROLL 开始扫描
```

触屏 HUD：

```text
TAP 点按波纹 · DRAG 环绕观察 · SWIPE UP 开始扫描
```

原因：用户已经处于 EXPLORE，`SCROLL TO EXPLORE MORE` 没有描述滚动后的状态变化；“开始扫描”能建立明确预期。提示只保留当前阶段的三个动作，不在屏幕上解释功能原理。

### 4.4 右侧品牌水印的边界

`.explore-brand-mark` 位于 `index.html` 18 行、`src/styles.css` 178–244 行，配置位于 `src/config.js` 91–112 行。它是右侧低透明度队徽，不是左上角 `.masthead__title`。

本轮建议保留，但应满足：

- 透明度不高于当前 0.15。
- 不与右侧模型切换面板争夺文字对比度。
- 白色扫光伪元素 `.explore-brand-mark::after` 若形成第二处眩光，可先停止动画，仅保留静态低透明度队徽；不要再叠加更亮的光扫。

## 7. 横幅上下露白的确定性修复

位置：`src/archive.css` `.archive-banner` 615–701 行。

根因边界：当前横幅自身没有底色，却用 `margin-top: 8vh` 和 `margin-bottom: 8vh` 制造外部间距。外边距不属于横幅绘制区域，任何相邻浅色层、折线伪元素或过渡叠层都可能从这里透出。只给图片或伪元素补色不能从结构上保证连续。

固定方案：取消外边距，把同样的 8vh 空间变成横幅自身的深色内走廊。

```css
.archive-banner {
  box-sizing: border-box;
  min-height: 88vh;
  margin-top: 0;
  margin-bottom: 0;
  padding: 8vh 0;
  background: var(--archive-bg);
}

.archive-banner__bg {
  inset: 8vh -6%;
  width: 112%;
  height: calc(100% - 16vh);
}

.archive-banner__overlay {
  inset: 8vh 0;
}

.archive-banner::before {
  top: 8vh;
}

.archive-banner::after {
  bottom: 8vh;
}
```

验收时必须检查横幅上、下各 8vh：任意像素都只能来自 `#05070d` 或横幅照片，不得出现 `#f4f7fb`、`#f7f9fb`、纯白或透明到浅色父层的区域。
