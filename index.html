机械部

Mechanical
  • 负责英雄、工程、步兵等机器人的机械结构设计：底盘、云台、机械臂、传动与轴系
  • 从立项、采购到设计、迭代的完整项目流程
  • 你将掌握：SolidWorks 三维建模、3D 打印、CNC 加工、装配与测试
希望你：喜欢动手造物，对结构有直觉；零基础可，部内有自学路线与老队员带教。

硬件部

Hardware
  • 设计、构建、维护全队的电子系统与供电网络
  • 核心模块：机器人主控板、超级电容功率控制板、无线充电接收系统
  • 你将掌握：元器件特性、KiCad PCB 设计、电源拓扑、硬件调试与维护
希望你：对电路世界好奇，细致耐心；提供从基础到进阶的完整自学建议。

电控部

Embedded Control
  • 开发 STM32 驱动程序，设计控制与信号处理逻辑
  • 整机调试与维护，追求"赛场级"稳定性
  • 你将掌握：C/C++、PID/LQR 控制、CAN 总线与 DJI 电机、滤波器、FreeRTOS
希望你：有热情、责任心强、能独立思考；零基础建议先自学 C++ 与 PID 控制（部内有教程）。

算法部

Algorithm & Vision
  • 处理相机、激光雷达等传感器数据，让机器人拥有"眼睛"
  • 自动瞄准（装甲板识别跟踪）、智能导航、全自动哨兵、雷达站
  • 你将掌握：OpenCV、YOLO 深度学习、卡尔曼滤波、TensorRT 部署、ROS
希望你：对 AI 与视觉着迷，愿意读论文写代码；代表作：局均易伤 1618.3s 全国第一的雷达算法。

WAYPOINT 06-B // SHIP'S LOG

常见问题

FAQ
Q & A
05 LOGS
零基础可以报名吗？

完全可以。教程面向零基础设计，历届许多队员入队时没有任何机器人经验。我们更看重热情、责任心与自学能力。电控方向建议提前自学 C++ 与 PID 控制，其余部门均有完整带教路线。

有专业或年级限制吗？

不限专业、不限年级。工学院与 ISD 同学居多，但商学院、理学院的同学也曾入选并成为骨干。

时间投入大吗？会影响学业吗？

比赛与交付节点前的投入会明显增加。建议在咨询或宣讲时了解当季节奏、训练安排与项目责任，再结合自己的课业规划决定；团队重视清晰沟通和长期协作。

如何报名？

RM2027 正式报名尚未开放。请关注公众号「HKUST ENTERPRIZE」、加入 QQ 招新群 581184202，或邮件联系 robomasterhkust@gmail.com 获取开招提醒。

我已有经验，应该怎么准备？

在报名时附上 GitHub、作品集、机器人项目或比赛经历即可。机械、嵌入式、硬件、算法与工程协作经验都会帮助你更快找到合适的项目入口。
