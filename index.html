WHAT IS ROBOMASTER // 赛事介绍

什么是 RoboMaster

机甲大师赛 · 全球大学生机器人对抗赛

RoboMaster 机甲大师赛是面向大学生的机器人对抗赛事。参赛队伍需要跨机械、硬件、电控与算法协作，自主完成多类机器人的设计、制造、调试与赛场部署。

ENTERPRIZE 自 2015 年起代表香港科技大学参赛。具体兵种、赛制与胜利条件会随赛季调整，请以当季官方规则为准。

视频通过 Bilibili 官方播放器嵌入，内容与版权说明以原视频页面为准。

DIVISIONS // 04 TRACKS

四大部门 · 选择你的航向

01

机械部

MECHANICAL

底盘、云台、机械臂、传动轴系——从立项、采购到设计、迭代的完整流程；掌握 SolidWorks 建模、3D 打印、CNC 加工与装配测试。

希望你：喜欢动手造物，对结构有直觉；零基础可，部内有自学路线与老队员带教。

02

硬件部

HARDWARE

设计并维护全队的电子系统与供电网络：主控板、超级电容功率板、无线充电系统；掌握 KiCad PCB 设计、电源拓扑与硬件调试。

希望你：对电路世界好奇，细致耐心；提供从基础到进阶的完整自学建议。

03

电控部

EMBEDDED CONTROL

开发 STM32 驱动与控制逻辑，整机联调，追求“赛场级”稳定性；掌握 C/C++、PID/LQR 控制、CAN 总线与 DJI 电机、FreeRTOS。

希望你：有热情、责任心强、能独立思考；零基础建议先自学 C++ 与 PID 控制。

04

算法部

ALGORITHM & VISION

让机器人拥有“眼睛”：自动瞄准、智能导航、全自动哨兵、雷达站；掌握 OpenCV、YOLO 深度学习、卡尔曼滤波、TensorRT 部署、ROS。

希望你：对 AI 与视觉着迷，敢读论文敢写代码；代表作是局均易伤 1618.3s 全国第一的雷达算法。

FLIGHT PLAN // 入队航线

入队航线

  1. STANDBY 现在

    获取开招提醒

    关注公众号、加入 QQ 招新群或发送邮件；正式安排发布后，从任一官方渠道获取报名入口。

  2. APPLICATION 约 9—10 月

    报名与选择方向

  3. TRAINING 招新期

  4. TRIAL 约 11 月

    基础考核与 RDC

    通过阶段任务检验学习成果，并在 Robot Design Contest 中组队设计、制造和调试机器人。

  5. ONBOARDING RDC 后

    面试与入队

    围绕热情、责任心、协作与实践复盘交流；通过后加入部门和具体项目组。

  6. SEASON 次年春夏

    进入完整赛季

    参与需求评审、研发、整机联调、开源整理与赛场保障，逐步承担稳定的项目角色。

时间线参考往年节奏（招新约 9—10 月，RDC 约 11 月）；RM2027 具体安排以公众号通知为准。

LOG // Q&A

常见问题

零基础可以报名吗？ +

完全可以。教程面向零基础设计，历届许多队员入队时没有任何机器人经验——我们更看重热情、责任心与自学能力。电控方向建议提前自学 C++ 与 PID 控制。

有专业或年级限制吗？ +

不限专业、不限年级。工学院与 ISD 同学居多，但商学院、理学院的同学也曾入选并成为骨干。

时间投入大吗？会影响学业吗？ +

比赛与交付节点前投入会明显增加。建议先了解当季节奏、训练安排与项目责任，再结合课业规划决定；团队重视清晰沟通与长期协作。

如何报名？ +

RM2027 正式报名尚未开放。关注公众号「HKUST ENTERPRIZE」、加入 QQ 招新群 581184202，或邮件 robomasterhkust@gmail.com 获取开招提醒。

我已有经验，应该怎么准备？ +

报名时附上 GitHub、作品集、机器人项目或比赛经历即可；机械、嵌入式、硬件、算法与工程协作经验都会帮你更快找到合适的项目入口。
