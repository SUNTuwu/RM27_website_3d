RoboMaster 战队宣传网站 设计调研报告

竞品网站拆解 · 设计趋势总结 · ENTERPRIZE 官网（robomaster.hk）建设建议 · 2026-07

调研总览

Executive Summary

调研了 RoboMaster 官方站点与 6+ 支强队（华南虎、狼牙、交龙、T-DT、RobotPilots、FEver 等）的线上宣传阵地，核心结论：

  • RoboMaster 圈没有"千篇一律的官网"——战队宣传主阵地其实是 微信公众号 + B站 + 官方论坛开源帖；独立官网是少数强队的"加分项"，谁先做出高质量官网，谁就能在圈层里形成差异化记忆点。
  • 有官网的强队分两大流派：① 工具生态派（华南虎 scutbot.cn：官网只是入口，真正品牌是 RM Search / SimulatorX / 招新系统等工具矩阵）；② 内容展示派（狼牙 langya_website：获奖/项目/成员/博客的学术实验室风格）。
  • 视觉语言的"行业基准"由 DJI 官方 robomaster.com 定义：深色底 + 高饱和点缀色 + 赛事视频英雄区 + 大字号粗体标题。战队官网普遍向这个方向靠拢。
  • 对 ENTERPRIZE 的建议：深色科技风 + 金色队色 + 五冠王叙事 + 开源项目墙 + 中英双语，用"内容展示派"结构承载"工具生态派"的开源资产（34+ GitHub 仓库是我们独有的素材富矿）。详见文末方案。

竞品逐个拆解

Case Studies

1️⃣ RoboMaster 官方 robomaster.com —— 行业视觉基准

设计手法（含实测色值）

  • 主品牌蓝 #0087EE/#0091FF，深色底 #212121/#181B22，点缀红 #C62127、青 #00A1D6，灰阶文字 #dadada/#979797
  • 字体：DJI 自有 Dji-Bold + Open Sans + 苹方 PingFangSC-Semibold
  • 首页即全屏赛事视频英雄区，大字号粗体标题，强视觉冲击
  • 导航：高校系列赛（对抗赛/联盟赛/AI挑战赛/培训体系/直播回放）、规则公告、媒体库、专属招聘通道、中英切换

可借鉴点

  • "视频优先"：开场 5 秒抓住访客（比赛集锦比任何文案都有说服力）
  • "大数字优先"：冠军数、开源数、队员数做成数据带
  • 深色主题是 RM 圈的"母语"，浅色官网反而显得外行

2️⃣ 华南理工 · 华南虎 —— 工具生态派（scutbot.cn 矩阵）参考度 ★★★★☆

架构与内容

  • 主站 scutbot.cn（LabWeb SPA）：实验室介绍、新闻、战队文化
  • 工具矩阵：RM Search 搜索引擎（search.scutbot.cn，已被官方论坛接入）、SimulatorX 模拟器、招新系统（hr.scutbot.cn，自研 HR_Go 开源）、赛程分析软件（schedule.scutbot.cn，累计响应 260 万+ 次请求）
  • GitHub 组织 scutrobotlab：SimulatorX(66★)、RM2021_simulation(45★)、srml 中间件(33★)、asuwave 网页上位机(32★)、HR_Go(22★)；README 中英双语小标题 + shields.io 徽章排

设计思路 + ⚠️ 维护教训

  • "开源即品牌"：网站不是宣传册，而是给全 RM 社区用的工具——用实用价值换传播与口碑
  • 招新完全线上化（自研报名-面试系统），本身即技术实力展示
  • ⚠️ 调研时 simulatorx.org 域名已被停放、scutbot.cn 无法访问（分析基于 Wayback 存档）——再强的内容矩阵，没有持续维护就会归零。官网架构必须假设"建站的人会毕业"
👉 对 ENTERPRIZE 的启示：我们的超级电容、雷达算法、无线 JLink 在 GitHub 已有 60–80 star 的自然流量，官网应把这些仓库前置成"开源项目墙"，而不是藏在页脚链接里。

3️⃣ 华中科技大学 · 狼牙战队 —— 内容展示派（langya_website）参考度 ★★★★★

架构与内容

  • 基于 Jekyll 学术模板（Lab Website Template）改造，已开源为 RM 战队官网模板
  • 标准模块：获奖展示 🏆 / 项目展示 🚀 / 成员卡片（分级：队长-技术负责人-队员）👥 / 博客 📝 / 新闻 📰 / 专利
  • 全部内容用 _members/_awards/_projects 等数据文件配置，低代码维护

设计思路

  • 干净克制的学术风：浅色为主、信息密度高、加载快
  • 可维护性优先：队员换届也能靠改 YAML 维持更新，不依赖某个会前端的人
  • GitHub Pages 零成本托管 + PR 预览，工程化流程本身就是招新卖点
👉 对 ENTERPRIZE 的启示：RM 圈已有现成的开源官网模板（狼牙 langya_website、湖工商 FEver 的 RM2026 官网框架），可以直接 fork 改造，把精力花在内容与视觉定制上，而不是从零造轮子。

4️⃣ 河北工业职业技术大学 · FEver —— 可直接 fork 的现代化框架参考度 ★★★★★

技术栈与结构（RM2026 开源）

  • Next.js 15 + React 19 + TypeScript + Tailwind CSS 4，仓库 chudie233/rm-team-fever，Vercel 零成本部署，附完整部署/域名/DNS/回滚教程
  • 导航仅四项：分组 / 项目 / 链接 / 加入我们；五大分组（机械/电控/硬件/视觉/运营）卡片 + 弹窗 + 每组独立详情页
  • 项目成果区每项带"文档/仓库"双链接与组别标签；招新报名表 + "72 小时回复"承诺

视觉风格（预览站实测）

  • "霓虹 on 黑"主题：近黑底 + 霓虹强调色（pink #EC4899 / cyan #22D3EE / emerald #10B981 / indigo #6366F1），每组一个霓虹色
  • 玻璃拟态卡片（rgba(255,255,255,0.05)）+ 同色 35% 透明度外发光边框
  • 首屏八字对仗口号"初心高于胜负，成长胜于输赢" + "2026赛季 招新进行中" + QQ 群号
👉 这是目前 RM 圈最成熟、可直接复用的官网框架——fork 后一周内可上线。其"分组弹窗+独立详情页"结构与 ENTERPRIZE 的四部门建制完全兼容。

5️⃣ 浙江大学 · Hello World —— 技术知识库即门面

浙大没有传统宣传官网，而是用 MkDocs Material 搭建技术 Wiki（zju-helloworld.github.io/Wiki）作为对外门面：导航为 首页/入门/开发指南/测试指南/贡献指南/组件说明，内容细到 PID、AHRS、电机、裁判系统。思路：把"技术传承文档"开放给全社区阅读，既沉淀内部知识，又对外展示工程深度。队训"求是，团结，兢业，至臻"。

6️⃣ 东北大学 T-DT / 深圳大学 RobotPilots / 上海交大宗龙 —— 无官网派

这三支顶级强队均无独立官网，宣传完全依赖：B站账号（T-DT 实验室）、微信公众号 + 微博（交龙）、RoboMaster 官方论坛开源帖（RobotPilots 几乎每个兵种都有开源）。

启示（反面）：没有官网意味着——搜索引擎里找不到官方叙事入口，赞助商看到的是零散的社交平台页面，新队员无法在 10 秒内看清"这支队伍是谁、强在哪"。这恰恰是 ENTERPRIZE 可以弯道超车的空白点：做出香港高校第一个高质量 RM 战队官网。

7️⃣ ENTERPRIZE 历史官网 —— 前车之鉴

旧站 robomasterhkust.com（Wix 搭建）已停用，存档显示其为深蓝（#101c36） splash 页 + 活动/论坛/成员列表结构，重"队内事务"轻"对外宣传"；新域名 robomaster.hk 目前只有 CNAME 指向、尚无内容。教训：用 Wix 类闭源平台 + 无内容维护机制 = 域名荒废。新站必须解决"谁来更新"的问题（数据文件配置化或静态站点生成器）。

RM 圈官网设计趋势总结

Design Patterns

🎨 配色

深色底（#0b0f1a 级别）+ 1 个队色主强调 + 1 个辅助色。避免多色混战；机甲金属灰做层次。

📐 布局

英雄区（视频/渲染图 + Slogan + 大数字）→ 成绩时间线 → 机器人/技术展示 → 开源墙 → 团队 → 招新 CTA → 赞助墙。

🔤 字体

标题：粗黑体/科技感无衬线，大字号 + 宽字距；正文：常规无衬线；英文队名做视觉锚点。

🎬 动效

滚动渐显、数字滚动计数、视频背景；克制使用，加载速度优先（招生季访问多在手机端）。

📱 响应式

移动端优先——招新对象主要刷手机；B站/微信嵌入卡片要能点开。

🌐 双语

国际赛区队伍普遍中英双语；对海外赞助商与交换生招新是刚需（ENTERPRIZE 的天然优势）。

ENTERPRIZE 官网建设方案

Recommendations for robomaster.hk

定位

"香港高校第一个高质量 RM 战队官网"——对外（赞助商/学校/媒体）是品牌门面，对内（招新）是转化漏斗，对 RM 社区是开源资产的总目录。

信息架构（建议栏目）

  1. 英雄区：比赛集锦视频背景 + "ENTERPRIZE · 国际赛区五冠王" + 大数字带（5 冠 / 34+ 开源 / 30+ 论坛项目 / 2015 建队）
  2. 成绩时间线：2015→2025，突出 2017–19 三连冠、2023–24 再冠、2025 浙江站冠军 + 雷达全国第一
  3. 技术展厅：超级电容（招牌）、雷达算法、串联轮腿、机械臂工程——每项配数据与开源链接
  4. 开源项目墙：GitHub 仓库卡片（名称/简介/star 数），直接对接 hkustenterprize 组织
  5. 团队：部门架构（机械/电控/硬件/算法/运营）+ "万国博览队伍"多元文化 + 毕业去向（DJI、华为等）
  6. 招新：RDC 校内赛介绍 + 报名入口 + 培训体系说明（这是官网最重要的转化目标）
  7. 赞助：赞助方案说明 + 历史合作伙伴 + 联系方式

视觉方向

推荐："深夜机甲"风 —— 深色底（#0B0F1A）+ 金色主强调（#F5A623，呼应 ENTERPRIZE 的进取感与冠军叙事）+ 青色辅助（#39C5FF，科技感）。与 DJI 官方同源的深色语言，但用金色建立独立识别度，避免淹没在一众蓝黑官网中。本调研目录下的《战队档案》HTML 即为该配色的实际演示。

技术选型（按推荐度排序）

方案说明适合
A. Fork FEver 框架（首推）chudie233/rm-team-fever：Next.js 15 + Tailwind 4 + Vercel，四部门结构直接兼容，附部署/域名/回滚教程，一周内可上线快速上线且视觉现代，队员换届可维护
B. Fork 狼牙 langya_websiteJekyll + GitHub Pages，YAML 配置内容，零成本零运维，学术风无前端能力时的保底方案
C. 双站组合（进阶）宣传官网（A 或 B）+ MkDocs Material 技术库子站（仿浙大 Wiki / SimulatorX 文档站），沉淀雷达/超级电容等开源文档把"开源大户"优势发挥到极致，形成头部队伍才有的差异化

落地节奏建议：先 fork FEver 框架占位（robomaster.hk 目前是空壳），内容用本次《战队档案》填充；随后逐步迁移到"宣传站 + 技术库"双站。不要再用 Wix 类闭源平台，也要吸取 simulatorx.org 域名荒废的教训——域名续费与构建流程必须写进交接文档。

视觉与文案细则

  • 配色：近黑底（#0B0D10～#181B22）+ 主强调金 #F5A623（冠军叙事）；若采用分组霓虹色方案（FEver 风格），可为机械/硬件/电控/算法各配一个霓虹色（cyan #22D3EE / pink #EC4899 / emerald #10B981 / indigo #6366F1）用于分组标签
  • 口号：首屏一句对仗八字口号（参考 FEver"初心高于胜负，成长胜于输赢"、华南虎"不要怂，就是干"），下方紧跟行动信息："RM2027 招新进行中 + QQ 群 581184202"
  • 字体：标题思源黑体/HarmonyOS Sans Bold（对标 Dji-Bold 效果），英文 Inter/Open Sans；中英双语小标题（如 "Dependencies | 项目依赖" 格式）提升专业感
  • 影响力数字区：3–4 个大数字卡片——国际赛区冠军×4（2016–2019）/ GitHub 开源 34+ 仓库 / 论坛阅读 2.1万+ / 雷达局均易伤 1618.3s 全国第一
  • README 规范：GitHub 仓库统一 shields.io 徽章排（License/Engine/自定义标语徽章）并回链官网

内容运营要点

  • 官网 ≠ 一次性工程：约定"赛季末开源季 = 官网更新季"，与论坛开源汇总帖同步
  • 中英双语至少覆盖首页与招新页（国际生源 + 海外赞助）
  • 每个开源项目卡片链回 GitHub 与论坛帖，形成"官网引流 → GitHub star → 论坛阅读"的循环
  • 招新季在公众号/B站所有内容挂官网链接，把社交流量沉淀到自有阵地
